## 主口径（2026-10-24 起）

主样本为**日常降雨**：剔除任一端 500 km 内有热带气旋、或任一端为易降雪日（CPC 日均气温 <2 °C）的连接-日，共 2,357 万个（占 82%）。运行 `RM_EVERYDAY=1 Rscript 06_全国回归.R …` 得到 `results/全国回归结果_日常.csv` 与 `results/vcov_日常/`；不设该变量时为旧口径（非台风日，含易降雪日），写入 `全国回归结果.csv`。图表（10）与损失（09）读日常口径；台风交互 T3、降水分相 S1、全部日 M 系列仍在 `全国回归结果.csv`。

- 日常日剂量-响应：起点小雨 −0.2%（不显著）、中雨 −1.8%、暴雨 −3.8%；终点小雨 −0.7%、中雨 −1.7%、暴雨 −5.8%。
- 易降雪日的降水：起点 0.1–10 mm −5.5%、10–25 mm −13.1%；终点小量降水 −3.7%。
- 年损失（亿人次）：日常降雨计入滞后 11.42（95% 置信区间 10.41–12.41），起点小雨记零 8.81；易降雪日 1.13、台风日 1.27（只计当天）。
- 论文 v0.4（`论文初稿/v0.4/`）按此口径重写。
- 日类型（2026-10-24，06 的 H 组；04 的 dtype 依 config.HOLIDAYS / ADJUSTED_WORKDAYS，来自国务院 2023—2025 年放假通知）：300 km 以内连接上，周末大雨、暴雨效应比工作日大四到五成（起点 −5.7%/−8.9% 对 −4.1%/−6.3%，终点 −6.3%/−9.3% 对 −4.1%/−6.2%，z 在 −2.2 到 −4.2 之间）；节假日不更大且不精确。已写入工作稿 5.2 节（改名为“距离与日类型”）、4.3、6.1、结论、投稿信，图 3 扩为 2×2；存档为 v0.5。

## 当前结果（2026-10-17）

主口径：非台风日（起终点 500 km 内均无热带气旋），控制前 7 日累计降水；模型 T2 / T4 / T5 / T6 与 N 系列。

- 主样本 2807 万个 OD-日（26,442 条稳定连接 × 1096 天，剔除 2.5% 的台风日）。
- 剂量-响应：起点 / 终点下雨 小雨 −0.6% / −1.0%，中雨 −1.9% / −1.8%，大雨 −2.3% / −3.1%，暴雨 −4.0% / −6.0%，大暴雨及以上 −5.5%（不显著）/ −8.8%。
- 距离：起点、终点下雨都是越近降得越多（暴雨：150 km 内约 −8.5%，千公里外 −2% 至 −7%）。
- 气候：非湿润区在每个雨档都比湿润区更敏感；剔除台风日后东部变为较不敏感的地区。
- 损失：非台风日降雨每年减少约 9.5 亿人次（85% 来自小雨和中雨），台风日另约 1.3 亿，合计 10.8 亿（2.2%）。
- 稳健性：OD×周固定效应、PPML、三向聚类下主结果基本不变；±7 天安慰剂仍有约 ±1 个百分点残余，小雨档结论需谨慎。
- 对照（全部日，M 系列）：≥100 mm 时 −22.4% / −27.1%，主要来自台风日；台风天气本身留待另文研究。
- CPC 观测格点（02c）已就绪：单元年降水与 ERA5-Land 站点相关 0.90；ERA5-Land 湿日占比 57.6%，CPC 49.2%，ERA5 判为小雨的单元日有 27% 在 CPC 里无雨。
- 气温控制（2026-10-22，06 的 Q 系列，同一 50% 连接抽样）：加入起终点日均气温分档后，雨档效应最多变动 0.2 个百分点（起点中雨 −1.9% → −1.7%，终点各档不变）。低温本身显著抑制流动（起点 <−10 °C 为 −12.9%，相对 15—20 °C）。
- 雨量计稳健性（G1，全样本）：改用 CPC 降水分档后，小雨与中雨效应基本不变（起点 −0.6% / −1.4%，终点 −1.0% / −1.7%）；大雨以上偏小（终点暴雨 −3.4%，主口径 −6.0%），可能因 0.5° 格点平滑了局地强降水。CPC 的小雨日比 ERA5-Land 少约六分之一，按 CPC 算小雨损失会相应变小。
- 论文稿（2026-10-23）已写入气温控制与 CPC 雨量计结果：摘要、引言、3.2 节与表 1、4.4、5.5、5.7 与表 3、6.4 局限、结论、数据声明与致谢、参考文献（Chen et al. 2008、Xie et al. 2007），中英文 Word 已重新生成。
- v0.2 安慰剂与区域冲击（2026-10-23，06 的 N7、P、R7、G5；04 新增 m01_*、pb_*、rg7_*）：
  - 小雨 ±7 天安慰剂（N7，三向聚类）基本干净：起点 +0.16% / +0.10%，终点 +0.41%（p<0.05）/ +0.01%。
  - 多期移位安慰剂（10 个移位）：平均值接近 0（−0.05% 至 +0.16%），正负交替，像噪声而非系统偏差；平均绝对值小雨约 0.3、中雨约 0.5、≥25 mm 约 0.6 个百分点；加大区×日期 FE 后缩小约三成到四成。
  - 终点小雨效应（−1.0%；大区×日期 FE 下 −0.7%）明显超出安慰剂噪声；起点小雨效应（−0.6%；大区×日期 FE 下 −0.2%）落在噪声带内，不稳。
  - 大区×日期 FE（R7）使中雨至暴雨效应缩小 16%—31%、起点小雨缩小 60%（起点缩得更多），剂量-响应与距离梯度保持；部分缩小可能来自吸收了大范围降雨变异造成的衰减。
  - 非台风日年损失区间：主估计 9.54 亿，大区×日期 FE 6.80 亿，CPC 降水 7.75 亿，扣除安慰剂 10.02 亿；中雨及以上 2.97—3.86 亿较稳；最保守（小雨记零）3.34 亿。
- 论文 v0.2（2026-10-23，`论文初稿/v0.2/`）已写入上述结果：新增表 3（移位安慰剂）、表 4（损失区间），原稳健性表顺延为表 5 并加大区×日期 FE 一行；摘要、亮点、结论的损失改为 7 亿至 10 亿人次；起点小雨不作为已确认效应。
- 分样本气温检验（2026-10-23，06 的 T45t，同一 50% 连接样本）：距离档与干湿分样本加气温后，小雨至暴雨系数最多变动 0.37 个百分点；起点干湿差距略有扩大（中雨 1.6 → 1.8、暴雨 2.6 → 3.0 个百分点）。已写入论文 v0.3（`论文初稿/v0.3/`），局限性中“尚未做”的说明已删。
- 模拟盲审后的补充分析（2026-10-23，`论文初稿/审稿意见_模拟盲审_20261023.md` 第 1、4、6 条；06 的 W、S、N7d、T5v，04 新增易降雪日 sn = CPC 日均气温 <2 °C）：
  - 降雪：易降雪日的降水影响远大于降雨（起点小雨 −5.5%、中雨 −13.1%；终点小雨 −3.7%）。分相后降雨本身：起点小雨 +0.1%（不显著）、中雨 −1.3%、暴雨 −3.4%；终点小雨 −0.6%、中雨 −1.6%、暴雨 −6.0%。干燥区 21% 的小雨日是易降雪日（湿润区 4%）。
  - 干湿差距：只看降雨时，起点中雨至暴雨仍有 1.2—2.3 个百分点的差距，小雨差距基本来自降雪；终点差距消失。5—9 月样本的起点差距约减半。
  - 损失（非台风日，亿人次，95% 置信区间）：主估计 9.54（8.93—10.14）；起点小雨记零 6.41（5.95—6.89）；动态模型只算当天 7.42（6.83—8.02）；计入当天至 3 天后的滞后 17.25（15.97—18.65）；滞后且起点小雨记零 11.92（10.84—13.10）。滞后效应使损失翻倍以上，主估计明显低估。
